# 字母雷电 · Alphabet Raiden

一个让小朋友认识字母的空战小游戏，真实山川湖泊航拍背景，支持全屏游玩。含两种模式：经典空战 与 BOSS 对决。

## 模式一 · 经典空战

敌机从屏幕顶部各处随机出现，带着字母沿弯曲航线扑向你的飞机；看清机身上的字母，按下相同字母按钮即可发射追踪能量弹把它击落。

- 🎯 你的飞机沿固定 8 字轨迹**自动前后左右移动**（无需操控），敌机终点实时追着它飞，子弹也从飞机机头发射
- 🔒 子弹自动锁定该字母中距离最近的敌机，无需手动瞄准
- 🌀 敌机有直扑、缓弯、S 弯、波浪、之字、大回环、螺旋、绕圈等多种弯曲航线，最终目标都是你的飞机
- ❤️ 敌机撞到你的飞机就会扣一条生命，生命耗尽游戏结束
- 🔊 命中时语音朗读字母，配合爆炸粒子、得分飘字与音效
- 🏆 连击加分、等级提升敌机速度，最高分按「模式+难度」保存在浏览器本地

## 模式二 · BOSS 对决

- 👾 只有一台 BOSS 飞机，在前方沿 8 字轨迹规律移动，带血条
- 🚀 BOSS 会发射带字母的导弹，导弹碰到你的飞机就扣血
- 🔤 BOSS 身上每隔几秒亮出一个新字母，按对应字母即可攻击它、削减血量；打光血量获胜
- ⚡ **优先规则**：如果某个字母同时出现在导弹和 BOSS 身上，按它会优先打掉导弹

## 三档难度

| 难度 | 字母范围 | 速度 | 生命 | 特点 |
|---|---|---|---|---|
| 🌱 简单 | A–F | 慢 | 5 | 直扑 / 缓弯，适合刚起步 |
| 🚀 中等 | A–M | 中 | 3 | 新增 S 弯 / 波浪 / 之字 / 大回环 |
| 🏆 困难 | A–Z | 快 | 3 | 含小写、螺旋 / 绕圈 / 三机编队 |

## 运行

用浏览器打开 `index.html` 即可玩（需与 `earth-bg.jpg` 放在同一目录）。 HUD 里的 ⛶ 按钮可切换真正的全屏模式。

也可在线试玩：https://kakshinji.github.io/alphabet-raiden/
