# 字母雷电 · Alphabet Raiden

一个让小朋友认识字母的空战小游戏。敌机从屏幕顶部各处随机出现，带着字母沿弯曲航线扑向你的飞机；看清机身上的字母，按下相同字母按钮即可发射追踪能量弹把它击落。

## 玩法

- 🎯 玩家飞机固定在底部不能移动，点击字母按钮（或电脑键盘字母键）发射子弹
- 🔒 子弹自动锁定该字母中距离最近的敌机，无需手动瞄准
- 🌀 敌机有直扑、缓弯、S 弯、波浪、之字、大回环、螺旋、绕圈等多种弯曲航线，最终目标都是你的飞机
- ❤️ 敌机冲到底线撞到你就会扣一条生命，生命耗尽游戏结束
- 🔊 命中时语音朗读字母，配合爆炸粒子、得分飘字与音效
- 🏆 连击加分、等级提升敌机速度，最高分按难度保存在浏览器本地

## 三档难度

| 难度 | 字母范围 | 速度 | 生命 | 特点 |
|---|---|---|---|---|
| 🌱 简单 | A–F | 慢 | 5 | 直扑 / 缓弯，适合刚起步 |
| 🚀 中等 | A–M | 中 | 3 | 新增 S 弯 / 波浪 / 之字 / 大回环 |
| 🏆 困难 | A–Z | 快 | 3 | 含小写、螺旋 / 绕圈 / 三机编队 |

## 运行

单个自包含 `index.html`，无任何依赖。直接双击用浏览器打开即可玩。
